## Задача 5 — соответствие канонической цепочке

```text
Среда разработки → Сборка → Пакет обновления → Установка обновления → Эталон → Компании
```

| Этап | В UI Control Plane | Статус |
|---|---|---|
| Среда разработки (DEV) | Косвенно: «Релизы», DEV в «Компании → Версии», Studio DEV | Частично, не как этап цепочки |
| Сборка (Build) | **Отсутствует** | API есть, UI нет |
| Пакет обновления (Release Package) | **Отсутствует** | API есть, UI нет |
| Установка обновления (Deployment) | **Отсутствует** | API есть, UI нет |
| Эталон (TEMPLATE) | Смешано: «Шаблоны», «Template», «Опубликован в эталон», legacy Module Publications | Есть, но терминология конфликтует |
| Компании | «Компании → Клиенты», версии клиентов | **Отражён** |

Скрыто в технических разделах:
- Module Publications / Applies / Rollbacks — legacy config pipeline
- Tenant Module Configurations / Configuration Diffs — tenant config, не code release
- Обновления модулей / Предпросмотр — module update offers, не Build→Package

## Задача 6 — рекомендуемая структура верхнего уровня

```text
1. Главная
   Сводка: компании, эталон, очередь поставки, предупреждения

2. Поставка изменений          ← новый логический раздел
   - Среда разработки (статус DEV)
   - Сборки
   - Пакеты обновления
   - Установки обновления
   - История поставки

3. Эталон
   - Текущая версия
   - Версии эталона
   - Публикация в эталон (legacy + canonical)

4. Компании
   - Список компаний
   - Лицензии
   - Версии у компаний

5. Состав платформы
   - Модули платформы
   - Обновления модулей (offers)
   - Предпросмотр изменений

6. Управление доступом
   - Пользователи
   - Роли
   - Глобальные пользователи

7. Профиль платформы
   (без изменений)

8. Мониторинг и журнал
   - Мониторинг
   - Журнал событий

9. Техническое (свернуто по умолчанию)
   - Настройки модулей компаний
   - Сравнение настроек
   - Глобальные политики
```

Обоснование: владелец и CEO видят **цепочку поставки** и **эталон** отдельно от технического module-config контура; минимум английского на верхнем уровне.

## Задача 7 — разделы без технических терминов

| Аудитория | Должны понимать без Build/Deployment/Diff/Tenant/Publication/Template |
|---|---|
| Владелец платформы | Главная, Поставка изменений (сборка→пакет→установка), Эталон, Компании, Профиль, Мониторинг |
| Генеральный директор | Главная, Эталон, Компании (сколько на актуальной версии), Мониторинг |
| Аналитик | Поставка изменений, Предпросмотр изменений, Сравнение настроек (переименованный Diff), Компании → Версии |

Не для бизнес-аудитории без сопровождения: Module Applies/Publications/Rollbacks, Tenant Module Configurations, внутренности модулей.
